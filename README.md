🏧 Simulador de Cajero Automático
Este proyecto consiste en un simulador de cajero automático desarrollado con HTML y JavaScript.

📌 ¿Qué hace el proyecto?
El programa simula el funcionamiento básico de un cajero automático.
El usuario puede:
Ingresar su tarjeta.
Ingresar y validar su PIN.
Intentar ingresar el PIN hasta un máximo de 3 veces.
Ingresar un monto para retirar.
Verificar si tiene saldo suficiente.
Realizar una extracción de dinero.

▶️ ¿Cómo ejecutar el proyecto?
Descargar o clonar el repositorio.
Abrir la carpeta del proyecto en Visual Studio Code.
Abrir el archivo index.html en el navegador.
Seguir las instrucciones que aparecen en pantalla.

🛠️ Tecnologías utilizadas
HTML5
JavaScript
Visual Studio Code
